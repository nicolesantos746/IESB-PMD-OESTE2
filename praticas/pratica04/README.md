# Meu Diário Acadêmico

## Descrição

O Meu Diário Acadêmico é um aplicativo desenvolvido em React Native com Expo.

O objetivo da atividade é criar uma tela inicial para cadastro rápido de disciplinas do semestre, utilizando Core Components, import/export, StyleSheet e Flexbox.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- Flexbox
- StyleSheet
- react-native-safe-area-context

## Criação do projeto

O projeto foi criado utilizando o template blank do Expo com o comando:

```bash
npx create-expo-app@latest meu-diario-academico --template blank
